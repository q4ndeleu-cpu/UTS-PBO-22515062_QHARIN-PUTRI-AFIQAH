Cara menjalankan:
1. Buka folder ini di VS Code.
2. Pastikan JDK sudah terpasang.
3. Buka terminal pada folder yang berisi semua file Java.
4. Jalankan: javac *.java
5. Jalankan: java Main

Semua file harus tetap berada dalam folder/package yang sama.
Contoh ini perlu dipahami, diuji, dan disesuaikan sendiri sebelum digunakan.
